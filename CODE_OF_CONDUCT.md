# Code of conduct

PdfNetStack follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, critique code rather than people, and help newcomers.
Harassment, personal attacks and discriminatory language are not tolerated in issues, pull
requests, discussions or any other project space.

Report unacceptable behaviour privately to the maintainer through the contact on the
[GitHub profile](https://github.com/jams4code). Reports are handled confidentially. Maintainers may
remove content and block participants who break these rules.
