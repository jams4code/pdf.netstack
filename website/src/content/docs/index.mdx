## Install

<Tabs syncKey="install">
<TabItem label="Library">

```bash
dotnet add package PdfNetStack
```

</TabItem>
<TabItem label="Command line tool">

```bash
dotnet tool install -g PdfNetStack.Tool
pdfnetstack optimize in.pdf out.pdf
```

</TabItem>
</Tabs>

Version 1.0.0 is on NuGet with the optimizer, page editing, encryption and the command line tool.
Drawing, fonts, forms, signatures, PDF/A, extraction and HTML to PDF are in the main branch and
ship with 1.1. Until then, [build against the source](/getting-started/#build-from-source).

## Proof, not promises

Measured on a mixed real world corpus of invoices, reports, manuals, scans and presentations, with
default options:

<div class="proof">
  <div><strong>1,296</strong> <span>files in the corpus, 569 MiB</span></div>
  <div><strong>17.6%</strong> <span>saved on the 1,003 files optimized</span></div>
  <div><strong>0</strong> <span>verification failures</span></div>
  <div><strong>0</strong> <span>differing pixels at 150 DPI, 2,161 pages</span></div>
</div>

Every optimized file was rendered with PDFium and compared with its original. The method is on the
[fidelity](/concepts/fidelity/) page and the numbers on [Benchmarks](/benchmarks/).

## Runs where .NET runs

| Target | Runs on | Dependencies |
|---|---|---|
| `net8.0`, `net10.0` | .NET 8, 9, 10 and later. Trim and Native AOT compatible | None |
| `netstandard2.0` | .NET Framework 4.6.2 to 4.8.1, Mono, Unity, Xamarin, .NET Core 2.0+ | `System.Memory` (Microsoft, MIT) |

CI runs the full test suite on .NET Framework 4.8, .NET 8 and .NET 10, on Windows, Linux and
macOS. No Ghostscript, no browser, no native binaries. The OCR add-on is the one exception: it
runs its models on ONNX Runtime.

<CardGrid>
<Card title="Safe on untrusted files" icon="approve-check">
Parsing and decoding are bounded in depth, size and time. Encrypted, signed and damaged files
are never rewritten by the optimizer. [Safety model](/concepts/safety-model/)
</Card>
<Card title="MIT all the way down" icon="open-book">
The core package has no dependencies on .NET 8 and later. CI blocks any runtime package that is
not on a reviewed license allowlist.
</Card>
