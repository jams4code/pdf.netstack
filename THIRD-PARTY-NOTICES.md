fixtures are synthetic images written by Pillow (MIT-CMU) with libjpeg-turbo (IJG, BSD-3-Clause
and zlib licenses) through `tools/make_jpeg_fixtures.py`; no code from either is used. The JPEG 2000
test fixtures are synthetic images written by Pillow with OpenJPEG (BSD-2-Clause) and by a small
encoder in `tools/make_jpx_fixtures.py` written from ITU-T T.800; their references are OpenJPEG's

JPEG with Pillow; the files are not committed. The JPEG encoder, the progressive writer, the
resampler, SSIM and the exhaustive Deflate encoder are written from ITU T.81, RFC 1951 and
published papers; no libjpeg, Zopfli or other code is used.
`tools/make_standard_fonts.py` reads glyph name mappings from fontTools (MIT; the Adobe Glyph List
it carries is BSD-3-Clause) and the Symbol and ZapfDingbats encoding tables from pypdf
(BSD-3-Clause); only the resulting code point numbers end up in the generated file. The font
test fixtures are synthetic fonts built by `tools/make_font_fixtures.py` with fontTools (MIT);
they contain no glyphs or data from any existing font. Their WOFF2 versions are compressed with
the brotli Python package (MIT), as are the Brotli test vectors of `tools/make_brotli_fixtures.py`,
whose sample text was written for the tests. HarfBuzz (MIT), through uharfbuzz
(Apache-2.0), records reference shaping results: the `Test-*.shaping.jsonl` files for the
synthetic fonts, and local comparisons through `tools/harfbuzz_reference.py`. No HarfBuzz code is used.
The CFF encoding fixtures (`Cff-*.cff`, `Cff-Encoded.otf`) are assembled by
`tools/make_cff_fixtures.py`, with fontTools for the OpenType one and to read the others back;
their glyphs are empty.
The BMP, TIFF and WebP test fixtures are synthetic images written by `tools/make_bmp_fixtures.py`,
`tools/make_tiff_fixtures.py` and `tools/make_webp_fixtures.py` with Pillow (MIT-CMU), which
brings libtiff (libtiff license, BSD style) and libwebp (BSD-3-Clause), and with ImageMagick
(ImageMagick License, Apache-2.0 style) for WebP options Pillow does not expose. Their reference
pixels are what those libraries decode, except where a script explains otherwise; no code from any
of them is used.
