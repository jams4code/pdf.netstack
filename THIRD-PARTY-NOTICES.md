## PdfNetStack.Html

`src/PdfNetStack.Html/Parsing/HtmlEntities.g.cs` lists the HTML named character references,
generated by `tools/make_html_entities.py` from https://html.spec.whatwg.org/entities.json. The
HTML Living Standard is Copyright (c) WHATWG (Apple, Google, Mozilla, Microsoft), licensed under
the Creative Commons Attribution 4.0 International License
(https://creativecommons.org/licenses/by/4.0/). The table keeps the names and code points; their
form is changed to C# arrays.

`src/PdfNetStack.Html/Css/UserAgent.cs`, the default style sheet, uses the values of the
rendering section of the same standard (https://html.spec.whatwg.org/multipage/rendering.html),
under the same license. The rules are rewritten and reduced for print.

`src/PdfNetStack.Html/Css/CssColor.cs` uses the named color table and the Lab, LCH, Oklab and
Oklch conversion matrices published in CSS Color Module Level 4
(https://www.w3.org/TR/css-color-4/), Copyright (c) World Wide Web Consortium, under the W3C
Software and Document License (https://www.w3.org/copyright/software-license/).

No other third party code or data; the package depends only on PdfNetStack.

## PdfNetStack.Ocr

Depends on ONNX Runtime (`Microsoft.ML.OnnxRuntime` and `Microsoft.ML.OnnxRuntime.Managed`,
Copyright (c) Microsoft Corporation, MIT License). Its native binaries ship with the package's own
`ThirdPartyNotices.txt`, listing permissively licensed components.

The recognition models are not shipped. `tools/fetch_ocr_models.py` downloads the PP-OCRv5 mobile
detection, text line orientation, Latin and Arabic recognition models, from PaddleOCR
(https://github.com/PaddlePaddle/PaddleOCR, Copyright (c) PaddlePaddle Authors, Apache License
2.0) as converted to ONNX by RapidOCR (https://github.com/RapidAI/RapidOCR, Apache License 2.0).
Whoever redistributes the model files keeps that license and notice with them. The pre and post
processing in `src/PdfNetStack.Ocr/Processing` is written from the published methods (DB text
detection, CTC decoding); no PaddleOCR or RapidOCR code is copied.

## Development only

Not shipped in any package: MSTest (MIT) for tests, and `pypdfium2` (Apache-2.0 and BSD-3-Clause)
plus NumPy (BSD-3-Clause) for the optional render comparison script in `tools/`. The JPEG test
fixtures are synthetic images written by Pillow (MIT-CMU) with libjpeg-turbo (IJG, BSD-3-Clause
and zlib licenses) through `tools/make_jpeg_fixtures.py`; no code from either is used. The JPEG 2000
test fixtures are synthetic images written by Pillow with OpenJPEG (BSD-2-Clause) and by a small
encoder in `tools/make_jpx_fixtures.py` written from ITU-T T.800; their references are OpenJPEG's
decodes. No OpenJPEG code is used.
`tools/make_lossy_corpus.py` draws its synthetic measurement files with NumPy and writes one
JPEG with Pillow; the files are not committed. The JPEG encoder, the progressive writer, the
resampler, SSIM and the exhaustive Deflate encoder are written from ITU T.81, RFC 1951 and
published papers; no libjpeg, Zopfli or other code is used.
`tools/make_standard_fonts.py` reads glyph name mappings from fontTools (MIT; the Adobe Glyph List
it carries is BSD-3-Clause) and the Symbol and ZapfDingbats encoding tables from pypdf
(BSD-3-Clause); only the resulting code point numbers end up in the generated file. The font
test fixtures are synthetic fonts built by `tools/make_font_fixtures.py` with fontTools (MIT);
they contain no glyphs or data from any existing font. Their WOFF2 versions are compressed with
the brotli Python package (MIT), as are the Brotli test vectors of `tools/make_brotli_fixtures.py`,
whose sample text was written for the tests. HarfBuzz (MIT), through uharfbuzz
(Apache-2.0), records reference shaping results: `Test-Arabic.shaping.jsonl` for the synthetic
font, and local comparisons through `tools/harfbuzz_reference.py`. No HarfBuzz code is used.
The CFF encoding fixtures (`Cff-*.cff`, `Cff-Encoded.otf`) are assembled by
`tools/make_cff_fixtures.py`, with fontTools for the OpenType one and to read the others back;
their glyphs are empty.
The BMP, TIFF and WebP test fixtures are synthetic images written by `tools/make_bmp_fixtures.py`,
`tools/make_tiff_fixtures.py` and `tools/make_webp_fixtures.py` with Pillow (MIT-CMU), which
brings libtiff (libtiff license, BSD style) and libwebp (BSD-3-Clause), and with ImageMagick
(ImageMagick License, Apache-2.0 style) for WebP options Pillow does not expose. Their reference
pixels are what those libraries decode, except where a script explains otherwise; no code from any
of them is used.
