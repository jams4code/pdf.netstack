## PdfNetStack.Html

`src/PdfNetStack.Html/Parsing/HtmlEntities.g.cs` lists the HTML named character references,
generated by `tools/make_html_entities.py` from https://html.spec.whatwg.org/entities.json. The
HTML Living Standard is Copyright (c) WHATWG (Apple, Google, Mozilla, Microsoft), licensed under
the Creative Commons Attribution 4.0 International License
(https://creativecommons.org/licenses/by/4.0/). The table keeps the names and code points; their
form is changed to C# arrays. No other third party code or data; it depends only on PdfNetStack.

## Development only

Not shipped in any package: MSTest (MIT) for tests, and `pypdfium2` (Apache-2.0 and BSD-3-Clause)
plus NumPy (BSD-3-Clause) for the optional render comparison script in `tools/`. The JPEG test
fixtures are synthetic images written by Pillow (MIT-CMU) with libjpeg-turbo (IJG, BSD-3-Clause
and zlib licenses) through `tools/make_jpeg_fixtures.py`; no code from either is used.
`tools/make_standard_fonts.py` reads glyph name mappings from fontTools (MIT; the Adobe Glyph List
it carries is BSD-3-Clause) and the Symbol and ZapfDingbats encoding tables from pypdf
(BSD-3-Clause); only the resulting code point numbers end up in the generated file. The font
test fixtures are synthetic fonts built by `tools/make_font_fixtures.py` with fontTools (MIT);
they contain no glyphs or data from any existing font. HarfBuzz (MIT), through uharfbuzz
(Apache-2.0), records reference shaping results: `Test-Arabic.shaping.jsonl` for the synthetic
font, and local comparisons through `tools/harfbuzz_reference.py`. No HarfBuzz code is used.
