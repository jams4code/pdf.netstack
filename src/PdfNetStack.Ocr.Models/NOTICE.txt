PdfNetStack.Ocr.Models

This package redistributes four PP-OCRv5 mobile models in ONNX format, unmodified:

  models/ch_PP-OCRv5_det_mobile.onnx                     text detection
  models/ch_PP-LCNet_x0_25_textline_ori_cls_mobile.onnx  text line orientation
  models/latin_PP-OCRv5_rec_mobile.onnx                  Latin script recognition
  models/arabic_PP-OCRv5_rec_mobile.onnx                 Arabic script recognition

The SHA-256 of each file is pinned in PdfNetStack.Ocr (OnnxOcrEngine.ModelHashes), checked when
the package is built and again when the models are loaded.
