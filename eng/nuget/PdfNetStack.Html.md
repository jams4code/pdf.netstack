# PdfNetStack.Html

HTML and CSS to PDF for .NET, in pure C#: no browser, no native binaries, MIT licensed.

> Status: in development. The HTML5 parser is in place; the CSS cascade, layout and paged media
> are being built. Follow the roadmap at https://github.com/jams4code/pdf.netstack.

Built on [PdfNetStack](https://www.nuget.org/packages/PdfNetStack), which provides the PDF
writer, font embedding, the Unicode line breaking and bidirectional algorithms, and an OpenType
shaper that matches HarfBuzz, so right to left and Arabic text come out right.

By Jamal Abdelkhalek, [JADEV](https://jadev-corp.com).
